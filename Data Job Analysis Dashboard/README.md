## Introduction
I wanted to explore the data job market to understand how salaries vary across different factors, which positions and skills are trending, and which platforms are most effective for finding data-related jobs.  
To answer these questions, I used a dataset from DataNerd.tech and built an interactive Excel dashboard analyzing the 2023 data job market.  

### Questions Explored  
1. What is the salary range for data jobs?
2. Which job platforms offer the most opportunities?
3. How strong is the demand for data-related roles?
4. What are the most in-demand skills?
5. How common are remote job opportunities?

### Excel Skills Used
- Power Query > Data Cleaning & Transformation
- Power Pivot > Data Modeling and Table Relationships
- Pivot Tables & Pivot Charts > Data Analysis and Visualization
- Excel Formulas and DAX
- Dynamic Dashboard Design


## Dashboard Overview
The dashboard allows users to dynamically filter insights using:
- Job Title
- Country
- Job Type
All KPIs and visualizations update automatically based on the selected inputs.

### KPIs Included
1. Median Salary
2. Top Hiring Platform
3. Total Job Count
4. Top Skill
5. Remote Job Count
